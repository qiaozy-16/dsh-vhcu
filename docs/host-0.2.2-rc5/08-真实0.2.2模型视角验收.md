## 3. 关键结论

1. **注册/执行契约在 0.2.2 上成立**：`ctx.tools.register` 的 28 个定义全部可用，`output{schema,render}` 正常渲染，错误码正常。
2. **视觉链路完整**：`mss` 捕获、差分、全屏、目标窗口 PrintWindow、UIA 查询、签名 frame_url 都可用。
3. **宏录制在真实桌面下正常**：这是影子环境唯一测不了的项目。影子 host 是 `ELECTRON_RUN_AS_NODE`，uiohook 全局钩子拿不到事件（0.2.1/0.2.2 同样），而真实 0.2.2 桌面进程成功记录 4 个事件、2 个步骤。
4. **物理急停是“物理光标”语义**：`mouse_click(0,0)` 走 hybrid 的虚拟路径，不移动物理光标，所以不会触发四角急停；这不等于急停失效，真实物理注入路径仍会在光标停角落时返回 `E_DENIED`。
5. **停止视觉后的错误路径正确**：`E_STATE` + 明确提示，不会静默成功。
