### 隔离启动预案（尚未执行）

0.2.2 桌面壳支持两个隔离点（实读 `lib/main.js`）：

- `DSH_HOME`：决定 `.dsh` 根（profiles / sessions / storage）；
- Electron `userData`：`app.getPath("userData")`，位于 `%APPDATA%\@deepseek-ai\dsh-desktop`。

建议影子启动时同时设置：

```
DSH_HOME=<workspace>/.tmp/dsh022-home
APPDATA=<workspace>/.tmp/dsh022-appdata
LOCALAPPDATA=<workspace>/.tmp/dsh022-localappdata
```

再从 `.tmp/dsh-022rc5/app/DeepSeek Harness.exe` 启动。这样不会读写真实
`C:\Users\mate\.dsh` 与 `%APPDATA%` 下的 0.2.1 数据。影子 profile 需要单独准备
（至少 `dsh-base` + `dsh-web-app` + `dsh-vhcu` + `dsh-better-sidebar`），
不能用真实 profile 直接指过去，避免插件管理写回真实组合。

### 宏录制为什么在影子里 0 步（重要结论）

这不是 0.2.2 的兼容性问题。用同一个 `uiohook-napi@1.5.5` 在三种进程形态下做最小测试：

| 进程形态 | 结果 |
|---|---|
| 0.2.2 Electron 44.7.0（`ELECTRON_RUN_AS_NODE=1`） | 全局键鼠事件 **0** |
| 0.2.1 Electron（同样 `ELECTRON_RUN_AS_NODE=1`） | 全局键鼠事件 **0** |
| 系统 Node 24.15 | 全局键鼠事件 **0**（合成输入/钩子在该非桌面宿主形态下不可靠） |

结论：**影子 host 用的是 `ELECTRON_RUN_AS_NODE` 的 headless 形态，uiohook 全局钩子在其中拿不到事件**；
真实 DSH 桌面进程不是这个形态，因此宏录制必须在真实桌面 UI 或升级后的真实宿主上验证，
不能把影子的 0 步当成 0.2.2 回归。

## 8. 升级阻塞：`%TEMP%` 当前不可写（2026-11-22 16:30 发现）

用户双击官方安装包时出现：

```
NSIS Error
Error writing temporary file. Make sure your temp folder is valid.
```

实测同机环境：

| 检查 | 结果 |
|---|---|
| `echo hi > C:\Users\mate\AppData\Local\Temp\probe.txt` | **Permission denied** |
| `mkdtempSync(%TEMP%/...)`（测试中） | **EPERM** |
| `npm` 默认缓存（在 `%LOCALAPPDATA%\npm-cache`） | **EPERM** |
| `icacls %TEMP%` | 存在 `CodexSandboxUsers` 与多个 `S-1-15-2-*` 显式项；`mate` 有继承的 FullControl |
| `whoami /groups` | **`Mandatory Label\Low Mandatory Level`（S-1-16-4096）** |

根因（2026-11-22 16:32 补正）：不是 DACL 缺权限（`mate` 已是 FullControl），
而是 **当前 DSH 工具进程运行在 Low 完整性级别**，`%TEMP%` 目录是更高完整性，
Windows 的 no-write-up 规则直接拒绝写入。因此：

- `diagnose-windows-sandbox-acl` 的 ACL 修复**不能解决**这个问题（它修 DACL/owner，不修完整性标签）；
- 在当前会话里也无法把 `%TEMP%` 降到 Low（Low 进程改不了更高完整性的对象）。

可行路径：

1. **已采用的绕过（推荐）**：给安装器显式指定一个 Low 完整性、可写的 TEMP/TMP：
   `<workspace>\.tmp\installer-temp`（本会话已创建并验证可写），
   启动脚本：`<workspace>\.tmp\install-022.cmd`。只影响安装进程，不改系统设置。
2. **彻底修复（可选，需正常桌面/管理员）**：在普通（Medium）PowerShell 中把
   `%TEMP%` 的完整性标签调整为 Medium/Low，或把用户 TEMP 指向一个新的用户目录；
   这一步需要非受限会话，不能从当前 Low 沙箱完成。

在 TEMP 绕过生效前，**不要执行真实升级**；影子环境不需要它。
