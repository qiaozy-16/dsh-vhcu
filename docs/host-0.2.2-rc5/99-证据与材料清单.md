## 4. 复现命令（只读）

```bash
WORKSPACE="D:/Users/mate/Documents/deepseek-harness/default-workspace"
PKG="$WORKSPACE/.tmp/hostdiff"

# 1) 列出 0.2.2 与 0.2.1 的类型差异
diff -rq "$PKG/x021/deepseek-ai-dsh-tools-0.2.1-rc.3/package/lib/types" \
         "$PKG/x022/deepseek-ai-dsh-tools-0.2.2-rc.5/package/lib/types" | grep -v '\.map'

# 2) 确认 exec 字段
grep -n "arguments" "$PKG/x022/deepseek-ai-dsh-tools-0.2.2-rc.5/package/lib/types/contracts.d.ts" | head
grep -n "tool.execute(exec.arguments" "$PKG/x022/deepseek-ai-dsh-tools-0.2.2-rc.5/package/lib/index.js"

# 3) 确认中间件仍在
grep -n "tools/execute" "$PKG/x022/deepseek-ai-dsh-tools-0.2.2-rc.5/package/lib/pipeline.js"

# 4) 确认本机 profile 无 tools 覆盖、无 PTC
grep -n "id: tools\|maxParallelSubCalls\|tool-presentation\|mode: ptc" \
  "C:/Users/mate/.dsh/profiles/desktop/cordis.patch.yml"

# 5) 体积/哈希
sha256sum "$WORKSPACE/.tmp/dsh-022rc5/dsh-0.2.2-rc.5.exe"
sha256sum "D:/deepseek-harness/resources/app.asar"
```

> `npm` 在本机默认 cache 会 EPERM；本会话用 `npm --cache "$WORKSPACE/.tmp/npm-cache"` 绕过，未改全局配置。
