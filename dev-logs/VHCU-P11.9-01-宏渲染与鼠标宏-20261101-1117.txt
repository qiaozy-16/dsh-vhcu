2. 鼠标动作与坐标变量
====================================================================
2.1 steps 新 op（host/lib/macros.js + Python _run_step）
  {op:"double_click", x, y}   左键双击（move → down/up ×2，间隔 50ms）
  {op:"right_click",  x, y}   右键单击（move → RIGHTDOWN → RIGHTUP）
  {op:"drag", x1,y1,x2,y2}    已有：左键按下→12 步插值→释放
2.2 坐标占位符
  - 校验：坐标可以是 0..100000 的整数，或形如 {{x}} 的字符串（≤40）；
  - macroVariables 扫描步骤所有字符串字段（text/x/y/x1..），按首次出现顺序去重；
  - Python _prepare_step：
      解析 text 与坐标字段里的 {{name}}（缺变量 E_PROTO）；
      鼠标 op 的坐标转 int，校验 0..100000；
      若传 scaleFactor，则 round(value*scale) 并写回；
      返回该步 coords 供 dry-run/结果展示。
2.3 run_macro 参数
  input.macro.run args: {steps, variables, scaleFactor?}
  Python run_macro(steps, variables=None, scale_factor=None)
  dry-run 返回 {steps,texts,coords,variables,scaleFactor,elapsedMs:0}
2.4 Node vhcu_run_macro
  新增 is_relative_to_image（boolean）：
    - true 且 lastFrameMeta 存在 → 传 scaleFactor；
    - 未取全屏 → E_STATE（先 vhcu_get_full_frame）；
    - 返回 scale_factor/coords 供核对。
  旧 text 参数仍兼容（variables.text）。

3. 内置鼠标宏（系统基础宏）
====================================================================
  macro_mouse_double_click  vars x,y        1 步 double_click
  macro_mouse_right_click   vars x,y        1 步 right_click
  macro_window_drag         vars x1,y1,x2,y2 1 步 drag
  全部 category=系统基础宏、builtin=true、只读可启停。
  示例：
    vhcu_run_macro({
      name:"macro_mouse_double_click",
      variables:{x:400,y:300},
      is_relative_to_image:true
    })
    → Python 解析变量 → round(400*scale), round(300*scale) → 双击；
      返回 variable_map {x:"400",y:"300"}、coords [[..]]、scale_factor。
  未取全屏直接 relative → E_STATE。
