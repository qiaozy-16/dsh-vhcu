0. 结论（先看这 6 条）
====================================================================
C1. Node HEAR_START_TIMEOUT_MS 从 10s 放宽到 30s；超时文案自动显示 30s。
C2. Python hear.py 对声卡四步加明确日志与 5s 上限：
      default_speaker
      get_microphone(id/name)
      all_microphones(include_loopback=True)
      mic.recorder(...)
    每步 print `[hear] audio: ...`；超时抛 HearAudioTimeout(E_AUDIO_DEVICE)。
C3. soundcard 抛出的异常会包装成 HearError(E_AUDIO_DEVICE)，
    `_run` 捕获后 `state.hear=error`、lastError 带 “E_AUDIO_DEVICE: ...”，
    Node 收到 hear.status error → UI 红灯 + stderr，不再静默卡死。
C4. 真机验证（本机）：
    - HearService.start() 8s 内 loading → listening；
    - 日志显示 default_speaker ok、all_microphones count=4、
      selected loopback device、mic.recorder opened、capture loop started。
C5. 测试：Node 45/45、Python 59/59。
C6. 仍保留 P12.2.5 的 taskkill 清场、30s 熔断、stderr 透传。

2. Python 修改（vision/vhcu_daemon/hear.py）
====================================================================
2.1 新增
      AUDIO_DEVICE_TIMEOUT = 5.0
      class HearAudioTimeout(HearError): pass
      _audio_device_call(label, func, timeout=5.0)
        - print "[hear] audio: <label> ..."
        - 在 daemon 线程里执行 func（防止 WASAPI 枚举死锁主线程）
        - done.wait(timeout)
        - 超时:
            print "[hear] audio: TIMEOUT ..."
            raise HearAudioTimeout("E_AUDIO_DEVICE",
              "<label> 超过 5s 未返回，无法获取系统内录设备", hint)
        - func 抛异常:
            print "[hear] audio: ERROR <label>: ..."
            raise HearAudioTimeout("E_AUDIO_DEVICE",
              "<label> 失败：<error>", hint)
        - 成功 print "[hear] audio: <label> ok"
2.2 _open_loopback(sc)
      print "resolving default speaker loopback"
      speaker = _audio_device_call("default_speaker", sc.default_speaker)
      print default_speaker name
      for identifier in (speaker.id, speaker.name):
          mic = _audio_device_call("get_microphone(...)", ...)
      mics = _audio_device_call("all_microphones(include_loopback=True)", ...)
      print count
      选中后 print "selected loopback device = <name>"
      找不到 → HearError("E_AUDIO_DEVICE", "没有找到...", hint)
2.3 _capture_loop

      recorder = _audio_device_call("mic.recorder",
                    lambda: mic.recorder(samplerate=16000, channels=1))
      print "mic.recorder opened; capture loop started"
      with recorder: ...

7. 已知边界
====================================================================
R1. 5s 上限按“每个声卡 API 调用”计算；正常一次启动总音频耗时通常 <1s。
R2. _audio_device_call 用 daemon 线程等待，若底层 C 调用永久死锁，
    该线程会残留到进程退出（无法从 Python 强杀 C 线程），
    但主 Hear 线程会抛错、UI 红灯，不会卡黄灯。
R3. 30s 预算包含模型加载与声卡获取；正常 1-8s。
R4. taskkill 全量清场的风险/opt-out 同 P12.2.5（VHCU_KILL_ALL_PYTHON=0）。
R5. 真实转写仍依赖系统正在播放声音。
