====================================================================

C5. 文本去重：dedupe_overlap() 找上一段结尾与新段开头的最长重合（≥2字），
    截掉重复；_flush_segment 内集成并更新 _last_text。
C6. 测试：Node 46/46、Python 64/64；
    新增 8s 边界、dedupe 正反例、_flush_segment 去重集成。

2. 任务二：音频重叠与去重
====================================================================
2.1 常量（hear.py）
      SILENCE_SEC = 0.6
      MAX_SEGMENT_SEC = 8.0
      OVERLAP_SEC = 0.5
      OVERLAP_FRAMES = 17   # 510ms
      PADDING_SEC = 0.2     # P13.1 保留
2.2 采集循环
      pending_overlap: list[bytes]
      自然静音切片 / 8s 强切后：
          pending_overlap = speech[-OVERLAP_FRAMES:]
          pending_at = now
      下一次 voiced 且 speech 为空：
          if pending_overlap and now - pending_at <= 2.0:
              speech.extend(pending_overlap)
          else:
              speech.extend(preroll)
          pending_overlap = []
      - 强切时保留的是真实语音尾部 0.5s，可补边界漏字；
      - 自然静音切时尾部多为静音，相当于静音 padding；
      - 超过 2s 未续话丢弃旧 overlap，避免跨句污染。
2.3 文本去重
      def dedupe_overlap(previous, current, min_chars=2):
          for size in range(min(len(prev),len(cur)), 1, -1):
              if prev[-size:] == cur[:size]:
                  return cur[size:].strip()
          return cur
      _flush_segment:
          raw = text
          text = dedupe_overlap(self._last_text, text)
          if raw != text: print("[hear] dedupe overlap: -N chars")
          空文本不 emit；否则 self._last_text = text; emit hear.text
      - 只做后缀/前缀精确去重，不改变 whisper 输出内容；
      - 最小重合 2 字，避免误删单字。
2.4 顺序
      采集 → VAD/8s 强切 → 保留 0.5s → 下一段 → whisper → dedupe → emit。

6. 已知边界
====================================================================
R1. 8s 强切仍可能把句子从中间切开，但 0.5s 重叠 + dedupe 已明显降低漏字。
R2. 自然静音切的 overlap 是尾部静音，不是语音；主要作用是 padding。
R3. dedupe 只做精确后缀/前缀匹配；同义改写/标点差异不会删。
R4. 折叠判断依赖 Chromium -webkit-line-clamp；DSH Electron 支持。
R5. 未对 UI 展开交互做自动化渲染测试，需重启人工点开确认。
