2. 本轮交付物
====================================================================
2.1 依赖
    命令：npm install uiohook-napi
    实际：uiohook-napi@1.5.5
    归位：devDependencies（POC 专用，避免生产包默认携带未使用的原生钩子）
    原生二进制：
      node_modules/uiohook-napi/prebuilds/win32-x64/uiohook-napi.node
      大小 169 KiB
    package.json：
      "devDependencies": { "uiohook-napi": "^1.5.5" }
      "scripts": { "poc:uiohook": "node vision/test_uiohook.js" }
2.2 POC 脚本
    文件：vision/test_uiohook.js（ESM，package type=module）
    行为：
      - import { uIOhook, UiohookKey } from 'uiohook-napi'；
      - keydown：打印键名/键码/修饰键/时间；
      - mousedown：打印按钮/坐标/点击次数/修饰键/时间；
      - wheel：打印方向/数量/旋转/坐标/时间；
      - 启动后打印四行提示；
      - Ctrl+C / SIGTERM：stop() 并退出。
    事件格式示例：
      [事件] 键盘按下 键=A 键码=30 修饰=Ctrl 时间=20:50:01.123
      [事件] 鼠标按下 按钮=1 坐标=(640,360) 点击次数=1 修饰=- 时间=...
      [事件] 滚轮 方向=-1 数量=1 旋转=0 坐标=(640,360) 时间=...
    注意：
      - 不写文件、不发网络、不注入按键、不读系统剪贴板；
      - 仅监听并打印，不 suppress 任何事件；
      - 不接入插件主逻辑。

4. 风险与未验证项
====================================================================
R1. POC 使用系统 Node 24 加载；Electron 内置 Node ABI 可能不同。
    N-API 通常兼容，但插件打包仍需 electron-rebuild/实测。
R2. 当前只验证“启动成功”，未验证键鼠事件回调；需人工按键。
R3. 原生全局钩子可能被 Windows Defender/EDR 拦截；
    本轮未执行完整 Defender 扫描，无法给出“绝不拦截”结论。
R4. 169 KiB 只是 win32-x64 prebuild；macOS/Linux/arm64 另计。
R5. uiohook-napi 放在 devDependencies：
    `npm install --omit=dev` 后 POC 不可用；生产插件也不会默认携带。
R6. 全局钩子具备 keylogger 行为特征，未来接入必须先做显式录制提示、
    暂停、隐私窗口过滤、预览后保存。
