0. 结论（先看这 7 条）
====================================================================
C1. macros.json 升级为 version 2：新增顶层 categories[]（含 builtin 标记）；
    宏新增 builtin 字段与 category；旧的单层 global 被迁移/清理。
C2. 内置分类「系统基础宏」（builtin:true）随插件播种，**不可删除**；
    其中宏为只读（不可编辑/删除），但可启用/禁用。
C3. 三个写死宏改造成参数化基础宏：
      macro_launch_app(app_name,text)
      macro_create_folder(path,folder_name)
      macro_browser_search(keyword)
    外加 save_file；旧 open_notepad_and_type / macro_create_vhcu_folder 迁移时移除。
C4. Python run_macro(steps, variables) 支持任意 {{name}} 多变量替换；
    缺变量 E_PROTO；dry-run 返回 texts/variables 便于验证。
C5. vhcu_run_macro 新增 variables 对象参数（text 仍兼容 = variables.text）；
    宏对象返回派生 variables 列表，模型可先查参数。
C6. UI 改为两级目录：
      一级：宏组列表（[+ 新建宏组]；自定义组可删除；内置组无删除）
      二级：组内宏列表（[+ 新建宏] 自动关联当前组；[← 返回组列表]）
    宏详情沿用 steps JSON 编辑；内置宏只读，自定义宏可保存/删除。
C7. 测试：Node 40/40、Python 45/45；真实 macros.json 已迁移并验证。

1. 数据契约（host/lib/macros.js）
====================================================================
1.1 文件结构 v2
  {
    "version": 2,
    "categories": [
      {"name":"系统基础宏","builtin":true},
      {"name":"我的自定义宏","builtin":false}
    ],
    "macros": [
      {"name":"macro_create_folder","description":"...",
       "category":"系统基础宏","builtin":true,"enabled":true,
       "steps":[{"op":"key","keys":["win","e"]},
                {"op":"type","text":"{{path}}"}]}
    ]
  }
1.2 常量/种子
  BUILTIN_CATEGORY = "系统基础宏"
  DEFAULT_CATEGORY = "我的自定义宏"
  seedCategories(): 系统基础宏(builtin) + 我的自定义宏
  seedMacros():
    macro_launch_app     Win+R → {{app_name}} → Enter → 1s → {{text}}
    macro_create_folder  Win+E → Ctrl+L → {{path}} → Enter →
                         Ctrl+Shift+N → {{folder_name}} → Enter
    macro_browser_search Win+R → bing → Ctrl+L → {{keyword}} → Enter
    save_file            Ctrl+S
1.3 迁移（load）
  - v1 无 categories → 从宏去重生成，补 builtin；
  - 保证两个种子分类存在；
  - 旧宏 open_notepad_and_type / macro_create_vhcu_folder 移除；
  - 同名内置宏（如旧 save_file[global]）升级为 category=系统基础宏、builtin=true；
  - 清空后的 legacy global 分类移除；
  - 缺失内置宏按 seed 补回；
  - 有任何迁移 → persist 回写（原子写）。
1.4 保护与 CRUD
  - deleteCategory(builtin) → E_DENIED；
  - deleteCategory(非空) → E_STATE（先清空）；
  - update/remove(builtin macro) → E_DENIED；setEnabled 允许；
  - addCategory 重名 E_CONFLICT；add 自动补分类；
  - list() 返回派生 variables[]（正则提取 {{name}}，按首次出现顺序）；
  - categoriesList() 返回 name/builtin/count。
1.5 真实库迁移

2. 变量执行器
====================================================================
2.1 Python（input.py）
  run_macro(steps, variables=None)：
    - variables 必须 dict，≤20 项；key 匹配 [a-zA-Z0-9_]{1,40}；value 必须 str ≤2000；
    - 对每个 type 步骤执行 re.sub(r"\{\{([a-zA-Z0-9_]+)\}\}")；
    - 缺失变量 → E_PROTO（列出缺失名与步骤号），不会带占位符执行；
    - dry-run 返回 {dryRun,count,steps[],texts[],variables[],elapsedMs:0}；
    - 真实执行返回 texts/variables/elapsedMs；每步失败 E_MACRO_FAILED。
  cli.py input.macro.run 传递 args.variables。
2.2 Node（lib/index.js）
  executeStoredMacro(macro,{variables})：
    - variables 对象校验（值 String()）；
    - 下发 {steps: macro.steps, variables}（不做 Node 侧替换，统一由 Python 执行）；
    - 返回 macro/variables（宏声明）/texts/dry_run/elapsed_ms/steps/frame_url。
  vhcu_run_macro(name, variables?, text?)：
    - text 兼容旧调用 → variables.text；
    - 宏不存在 E_NOT_FOUND、禁用 E_DENIED。
  旧 vhcu_macro_open_notepad_and_type(text)：
    → apply macro_launch_app with {app_name:"notepad", text}。
2.3 示例
  vhcu_run_macro({
    "name":"macro_create_folder",
    "variables":{"path":"<local-path>","folder_name":"VHCU_P118"}
  })

3. UI（lib/client.js）
====================================================================
3.1 一级：宏组列表
  - 打开设置默认显示所有 categories；
  - 行：▶ + 组名 + “N 个宏 · 内置不可删除”；
  - 点击进入二级；
  - 自定义组右侧 🗑（stopPropagation）→ deleteCategory；
  - 底部 [+ 新建宏组] → 输入组名 → addCategory；
  - 同时保留调试/输入法设置与「保存设置」。
3.2 二级：组内宏列表
  - 顶部 [← 返回组列表]；
  - 标题「组名 (N)」；
  - 每行：checkbox 启停 + 宏名 + “N 步 · 描述 · 参数 x,y · 内置”；
  - 点击进入宏详情；
  - 底部 [+ 新建宏]：名称/描述/steps JSON，自动 category=当前组；
  - 不提供手填分类，避免放错组。
3.3 宏详情
  - 内置宏：分类/描述/steps 只读，隐藏保存/删除，仅返回；
  - 自定义宏：可改分类/描述/steps，保存修改 / 删除宏 / 返回。
3.4 刷新
  - GET /vhcu/macros 返回 macros+categories；
  - 增删改组/宏后本地立即更新；
  - 模型 vhcu_save_macro 后 macrosRevision 变化 → 打开着的设置自动重拉。

4. 接口
====================================================================
  GET  /vhcu/macros → {ok, macros[], categories[], revision}
  POST /vhcu/macros
    {action:"save", macro:{...}}
    {action:"toggle", name, enabled}
    {action:"update", name, macro:{category?,description?,steps?}}
    {action:"delete", name}
    {action:"addCategory", name}
    {action:"deleteCategory", name}
  错误码：E_CONFLICT / E_NOT_FOUND / E_DENIED / E_STATE / E_PROTO
  其余工具/路由不变（13 tools、6 routes）。
