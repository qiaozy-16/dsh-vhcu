2. 本轮交付物
====================================================================
2.1 隔离内存剪贴板
    变量：
      const MEMORY_CLIPBOARD_MAX = 5000;
      let memoryClipboard = '';
    工具：
      vhcu_set_memory_clipboard(text)
        - text 超过 5000 字 → E_PROTO，不截断、不写系统剪贴板；
        - 成功：{ok, text, length, max_length:5000, isolated:true}
        - Action 日志：📋 写入内存剪贴板 (N 字)
      vhcu_get_memory_clipboard()
        - 返回 {ok, text, length, empty, isolated:true}
        - 空时 text=''、empty=true
        - Action 日志：📋 读取内存剪贴板 (N 字)
    隔离：
      - 纯 Node 字符串，无 clipboard 模块、无 child_process 调 PowerShell、
        无 OpenClipboard/GetClipboardData/SetClipboardData；
      - DSH 重启即清空，不落盘；
      - UI/SSE 的 action 事件只含字符数，不含正文。
    工具数：
      19 → 21（视觉/键鼠/宏 16 + Hear 3 + 内存剪贴板 2）。

2.2 P19 调研报告
    文件：VHCU-P19-01-宏录制底层监听技术调研.md
    内容：
      - 需求/约束/安全底线；
      - uiohook-napi：N-API、键盘+鼠标+滚轮、MIT、prebuilt
        win32-x64 约 174KB 级、无需 node-gyp；风险为原生二进制/AV/
        低层钩子超时/窗口上下文需另查；
      - node-global-key-listener：仅键盘、外部二进制、0.3.0 旧包、
        ReversingLabs 标记历史恶意事件/供应链风险；不推荐；
      - ffi-napi + SetWindowsHookEx：需 Windows 消息循环、
        FFI 回调/线程/ABI 风险、维护性差；不推荐；
      - 自研 N-API 插件：最可控，推荐 V1.0 生产；
      - Raw Input (RIDEV_INPUTSINK)：备选，需原生窗口/消息循环，
        原始 HID 映射成本高；
      - Electron globalShortcut/页面监听/PowerShell/GetAsyncKeyState
        不适用；
      - AV/供应链/签名/打包 asar unpack/钩子生命周期；
      - POC 验收指标与推荐路线。

4. 风险与未验证项
====================================================================
R1. 内存剪贴板是明文进程内存；DSH 进程被调试/倾倒时可见。
R2. get 工具会把全文返回给模型；不要用内存剪贴板传递密码/密钥。
R3. 5000 字按 JS string.length（UTF-16 code unit）计算；
    emoji 可能占 2，达到上限时可能比“5000 个用户可见字符”少。
R4. Action 日志只记字符数，不记正文；但工具返回值含正文，
    模型上下文仍会包含，需谨慎。
R5. P19 调研基于公开资料与推断，未在本机安装 uiohook-napi 验证；
    其体积/API/兼容性以 POC 实测为准。
R6. node-global-key-listener 的恶意事件是第三方扫描历史记录，
    不代表当前版本一定恶意，但足以作为不引入理由。
R7. 全局键盘钩子天然具备 keylogger 行为，可能触发 AV/EDR；
    录制功能上线前必须做显式提示、暂停、隐私窗口过滤、预览后保存。

5. 待确认决策（编号）
====================================================================
D1. 内存剪贴板上限 5000 字；超限拒绝而非截断（避免静默丢数据）。
D2. 内存剪贴板不持久化，DSH 重启清空。
D3. 剪贴板工具只返回纯文本，不做富文本/图片。
D4. P19 POC 选 uiohook-napi；V1.0 生产建议自研 N-API 插件。
D5. 不引入 node-global-key-listener；不用 ffi-napi 做钩子。
D6. 录制功能必须显式开始、可见、可停、默认不自动执行。
