1. UI（lib/client.js）
====================================================================
1.1 列表 → 详情
  - 每行 role=button/tabIndex=0，点击或 Enter/Space 打开详情；
  - checkbox 的 onClick stopPropagation，不会误触发详情；
  - 详情面板字段：
      分类（可编辑，默认 global）
      描述（可编辑）
      steps（textarea，rows=9，原生 JSON）
    按钮：保存修改 / 删除宏 / 返回列表
  - 保存：JSON.parse(steps) → POST {action:'update', name, macro:{category,description,steps}}
    失败（JSON 语法/校验）显示中文错误。
  - 删除：POST {action:'delete', name} → 关闭详情并刷新列表。
1.2 分组与折叠
  - 客户端按 macro.category 分组；global 固定第一，其余按名称排序；
  - 组头按钮：`▼ category (N)` / `▶ category (N)`，点击折叠/展开；
  - 新建表单包含「分类（默认 global）」输入，保存后进入对应组。
1.3 刷新
  - 打开设置 → GET /vhcu/macros；
  - 增删改后更新本地 macros/revision；
  - 模型保存宏触发 status.macrosRevision 变化 → 打开着的浮层自动重拉。

2. 宏数据契约与 API
====================================================================
2.1 macros.js
  - normalizeCategory(raw)：trim → 默认 'global'，≤40 字符；
  - normalizeMacro 输出 {name,description,category,steps,enabled}；
  - seedMacros 内置两条 category='global'；
  - load()：若旧数据缺 category，解析后 persist 回写（一次性迁移）；
  - update(name, patch)：合并 description/steps/category/enabled，重校验，
    persist，revision++；name 本身不允许改（找不到 E_NOT_FOUND）。
2.2 API
  POST /vhcu/macros
    {action:'save',   macro:{name,description,category,steps}}
    {action:'toggle', name, enabled}
    {action:'update', name, macro:{category?,description?,steps?,enabled?}}
    {action:'delete', name}
  GET /vhcu/macros → {ok, macros[], revision}
2.3 工具
  vhcu_save_macro(name, description, category?, steps)
    category 缺省 global；其余校验/持久化同 P9。
  vhcu_run_macro 不变；禁用时 E_DENIED。

5. 重启验证
====================================================================
5.1 重启
  完全退出 DSH（确认 Electron/python.exe 无残留）→ 重开 → 新会话。
  日志：
    dsh-vhcu: mounted (routes /vhcu/state|events|control|frame|settings|macros)
    dsh-vhcu: registered 13 tools
5.2 宏 UI 验收
  1) VHCU → ⚙：应看到 `▼ global (2)` 与 `▼ explorer (1)`；
  2) 点组头可折叠/展开；
  3) 点 macro_create_vhcu_folder → 详情中 steps 为纯键盘（无 click），
     分类 explorer；
  4) 修改描述/步骤 → 保存修改 → 重新打开确认；
  5) 新建宏时填分类 demo → 出现 demo (1) 组；
  6) 删除一个测试宏 → 列表消失；重启后不再出现；
  7) 重启 DSH 后编辑内容与自定义宏仍在（macros.json 持久化）。
5.3 键盘宏验收
  先 vhcu_start_vision，然后：
    vhcu_run_macro("macro_create_vhcu_folder")
  预期：Win+E 打开资源管理器 → Ctrl+L 地址栏 → <local-path> → Ctrl+Shift+N →
  输入 VHCU_Learned → 回车；返回 elapsed_ms/steps/frame_url。
  若资源管理器启动慢，可把首个 wait 调大（详情面板直接改 JSON 保存）。
5.4 失败排查
  - 详情保存报 JSON 无效：检查 steps 文本（必须数组，op 在白名单）；
  - E_CONFLICT：新建时重名；
  - E_NOT_FOUND：编辑/删除的宏已被移除；
  - E_DENIED：宏被禁用；
  - 400/E_PROTO：category 超 40 字符、steps 非法。
