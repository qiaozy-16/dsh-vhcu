1. 复读机幻听过滤（hear.py）
====================================================================
1.1 is_repetitive_text(text, min_repeat=3)
      英文：
        - 提取小写单词（字母/数字/撇号）；
        - 对 n=1..min(8, len/3+1) 统计 n-gram 出现次数；
        - 任一 n-gram >=3：
            n>=2 直接判定；
            n==1 要求单词长度 >=3 且不是停用词
            （the/a/an/and/to/of/i/you/it/is/in/on 不触发）。
      中文：
        - 提取连续汉字片段；
        - 对 n=2..min(8, len/3+1) 统计重复；
        - 任一 >=3 → 判定。
      示例：
        "When the fire burns out " * 4 → True（5-gram ×4）
        "fire fire fire" → True（单词 ×3）
        "爆炸爆炸爆炸" → True（2 字 ×3+）
        "请打开设置，然后点击保存" → False
        "the the the" → False（单字停用词）
1.2 调用位置
      _flush_segment 转写完成后、短词过滤之前：
        if is_repetitive_text(text):
            print("[hear] discarded repetitive hallucination: ...")
            emit_ambient("repetitive")   # rms>=0.03 时仍有 🎵
            return
      → 不 emit hear.text，不进入融合文本。
1.3 未改动
      - 短词三条件过滤保持；
      - whisper 参数保持；
      - 环境音阈值 0.03 保持。

2. 融合层暴露 RMS 峰值（fusion.js）
====================================================================
2.1 已有字段
      audio_count, audio_rms, audio_rms_max, audio_rms_min, has_spike。
2.2 显示格式
      audioText = `[RMS:${avg} | 峰值:${max}${hasSpike ? ' 💥 巨响/音效' : ''}]`
      示例：
        👂 [RMS:0.16 | 峰值:0.45]
        👂 [RMS:0.08 | 峰值:0.50 💥 巨响/音效]
      hear_text / hear 字段同步；仅音频、音频+转写、both 均适用。
2.3 工具
      vhcu_get_multimodal_events 每条继续返回
      audio_rms / audio_rms_max / audio_rms_min / has_spike，
      模型可比对平均与峰值。
2.4 UI
      [M] 融合行听觉 chip 直接显示上面的字符串；
      8 秒窗口内即使平均只有 0.16，峰值 0.45 仍可见。

7. 已知边界
====================================================================
R1. 重复检测基于 n-gram：真实歌词/演讲有意重复 3 次也会被丢。
R2. 中文只检测连续汉字片段；中英混合重复可能漏检。
R3. 单字停用词重复不触发；其他 3 字母以上单词仍可能误判。
R4. 融合显示只用平均与峰值；谷值仍在字段中，不写进 hear_text。
R5. soundcard 无软件增益；调系统音量是唯一手段。
R6. 真实复读/爆炸片段需重启后人工验证。
