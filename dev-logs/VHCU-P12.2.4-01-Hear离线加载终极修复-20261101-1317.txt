    - 旧缓存：删除 models/.locks、models/models--Systran--faster-whisper-base、
      *.incomplete（保留 faster-whisper-base 本地模型）。
C4. UI 的 loading 提示现在显示 hear.status 的 message（真实检查路径/加载方式），
    不再只有笼统的“模型加载中”。

    - load_whisper_model(WhisperModel, models) 离线加载 1.03s；

====================================================================
1. 为什么之前会一直黄灯
====================================================================
可能原因（按优先级）：
  a) 点在旧 Python 守护进程上：DSH 未完全退出，旧进程/旧代码仍在跑，
     即使文件已改，实际执行的还是旧 hear.py；
  b) 旧 Hear 线程仍持有旧模型/加载状态，没有 stop 就再次 start；
  c) HF 缓存/锁残留让 huggingface 逻辑卡住（用户已手动清理）；
  d) 加载失败但错误没有显示到 UI 的 loading 文案里，看起来像“卡黄”。
本次同时处理 a/b/c，并把 d 的 message 暴露到 UI。

2. 实现（vision/vhcu_daemon/hear.py）
====================================================================
2.1 local_offline_model_dir
      root = (Path(model_root) or default_model_dir()).expanduser().resolve()
      for candidate in (root/"faster-whisper-base", root):
          found = (candidate/"model.bin").is_file()
          print(f"[hear] 检查离线模型路径: {candidate} (model.bin={found})")
          if found: return candidate.resolve()
2.2 load_whisper_model
      root = ...resolve()
      print("[hear] 模型根目录(绝对路径): ...")
      offline = local_offline_model_dir(root)
      if offline:
          print("使用本地离线模型加载: <abs>")
          print("[hear] OFFLINE_MODEL path=<abs> local_files_only=True")
          model = whisper_model_cls(
              str(offline), device="cpu", compute_type="int8",
              local_files_only=True
          )
          return model, str(offline), True
      force_hf_mirror()
      model = whisper_model_cls("base", ..., download_root=str(root))
      return model, str(root), False
2.3 HearService.start
      if old thread alive:
          print("[hear] 检测到旧 Hear 线程，先停止并释放模型")
          self.stop()                    # join + model=None + gc
      self._model_path = str(default_model_dir().resolve())
      print("[hear] 模型根目录(绝对路径): ...")
      cleanup_stale_cache(self._model_path)
      _import_dependencies()
      ... 启动 vhcu-hear 线程
2.4 cleanup_stale_cache
      - 删除 <root>/.locks
      - 删除 <root>/models--Systran--faster-whisper-base
      - 删除 <root>/**/*.incomplete
      - 每条输出 “[hear] 已清理旧缓存: ...”；不触碰 faster-whisper-base
2.5 status/message
      _run 先 emit loading:
        “检查本地离线模型（models/faster-whisper-base）…”
      加载后再 emit:
        offline → “使用本地离线模型加载: <path>”
        否则   → “本地模型不存在，从 HF 镜像 … 下载”
      status 含 offline/loadedPath。

6. 重启验证
====================================================================
6.1 必须完全退出 DSH
  关闭所有 DSH 窗口 → 任务管理器确认没有 python.exe / Electron 残留；

  UI：
    - 黄灯短暂出现后迅速变绿（本机实测加载 1s 级）；
    - loading 提示显示实际路径；
    - 绿后显示“使用本地离线模型 ...”。
6.4 断网验证
  断开网络后重启 DSH 再开 Hear，仍应变绿（local_files_only）。
6.5 若仍黄
  把 UI loading 提示/daemon stderr 的 “[hear] 检查离线模型路径” 行发我；
  可能原因：
    - 路径不是 <local-path> 指错）；
    - 文件不在 faster-whisper-base 子目录；
    - DSH 仍有旧 python.exe 未退出；
