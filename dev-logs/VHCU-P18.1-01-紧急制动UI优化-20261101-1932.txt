2. 快捷键
====================================================================
2.1 实现（client.js useEffect）
      window.addEventListener('keydown', handler)
      handler:
        key = event.key.toLowerCase()
        if ((ctrlKey || metaKey) && shiftKey && key === 'x'):
          preventDefault()
          if (!event.repeat) emergencyStop()
      返回时 removeEventListener。
2.2 触发条件
      - DSH 窗口处于活动/聚焦状态（前端监听，不是 OS 全局钩子）；
      - 浏览器/DSH 页面能收到 keydown；
      - 忽略长按 repeat，避免连发；
      - busy 时 emergencyStop 内部直接返回。
2.3 行为
      与点击图标完全一致：
        POST /vhcu/emergency-stop
        → doEmergencyStop
        → supervisor.stop + taskkill /F /IM python.exe
        → state 复位。
2.4 说明
      未做系统级全局键盘钩子；这是“DSH 窗口活跃时”的前端快捷键，
      与用户要求一致。

7. 已知边界
====================================================================
R1. 快捷键仅 DSH 窗口聚焦时有效；不是 OS 全局热键。
R2. Ctrl+Shift+X 若被宿主/输入法占用，可能收不到 keydown。
R3. busy（启动/停止中）时点击/快捷键不触发，避免重复请求。
R4. 图标为 ⏹（停止符号）+ 红色描边，不是高对比大按钮；
    极端情况下用户需要找到右上角。
R5. 底层 taskkill 仍会杀掉本机所有 python.exe，这是紧急制动代价。
