====================================================================
1. 返回图片的倍率契约
====================================================================
1.1 full_frame（lib/index.js captureFullFrame）
  image_width  = min(capture.width, max_width)
  image_height = round(capture.height * image_width / capture.width)
  scale_factor = round6(capture.width / image_width)
  返回 JSON 增加：
    image_width / image_height / scale_factor
  示例：屏幕 1920x1080，max_width=800 → image 800x450，scale_factor=2.4。
  message 附带：“基于该图片测量的坐标点击时请传 is_relative_to_image=true”。

1.2 vision events（diff handler + recentDiffEvents）
  每个 ROI：
    image_width  = min(roi.w, 960)          # frame_url 默认 max_width=960
    image_height = round(roi.h * image_width / roi.w)
    scale_factor = round6(roi.w / image_width)
  事件级：scale_factor = 首个 ROI 的 scale_factor（便于整体理解）。
  recentDiffEvents 对旧 ring 条目也补算缺失字段，保证返回契约稳定。

====================================================================
2. 点击自动映射
====================================================================
2.1 Node（vhcu_mouse_click）
  参数：x, y, is_relative_to_image(boolean, 可选)
  - relative=false：args {x,y}（旧行为，物理像素）；
  - relative=true：
      若 lastFrameMeta == null → E_STATE（先取全屏）；
      args {x,y,scaleFactor}；
      返回 {requested:[x,y], x:applied_x, y:applied_y, scale_factor, is_relative_to_image}；
      message：“图片坐标 (x,y) × scale ⇒ 物理坐标 (ax,ay)，已点击。”
  - lastFrameMeta 在每次成功 full_frame 时更新；
    start/stop/restart 时清空（避免分辨率变化后的陈旧倍率）。
2.2 Python（input.click）
  click(x, y, scale_factor=None)：
    - int 校验 x/y；
    - scale 默认 1.0，必须 0.1..10，否则 E_PROTO；
    - real_x = round(x*scale)，real_y = round(y*scale)；
    - normalize_click 后再 SendInput；
    - dry-run 返回 requested/scaleFactor/applied/normalized；
    - 真实点击同样返回 applied。
  cli.py input.click 读取 args.scaleFactor 传入。
2.3 责任边界
  模型只负责“在图片上量像素”；倍率乘法在 Python 守护进程内完成，
  符合“大模型不负责数学计算”的架构原则。

5.3 自动点击
  让模型在图片坐标 (100,50) 点击并传 is_relative_to_image=true：

  不再需要模型心算 1920/800。

7. 已知边界与下一步
====================================================================

    full-frame relative 按整图映射。
