1. 设置面板布局
====================================================================
1.1 CSS 修改（client.js）
      .vhcu-field {
        display:flex;
        flex-direction:column;
        align-items:stretch;
        gap:5px;
        padding:7px 0;
        margin:8px 0;
        color:#c6d2e2;
      }
      .vhcu-field + .vhcu-field { margin-top:12px; }
      .vhcu-field label {
        flex:none;
        font-size:11px;
        color:#aab6c8;
        font-weight:600;
      }
      .vhcu-field input[type=checkbox] {
        align-self:flex-start;
        width:16px;
        height:16px;
        accent-color:#4d6bfe;
      }
      .vhcu-select {
        width:100%;
        box-sizing:border-box;
        background:#0d1016;
        color:#d7dee8;
        border:1px solid #2b3442;
        border-radius:4px;
        padding:3px 4px;
        font:inherit;
      }
1.2 效果
      - 听觉灵敏度：标题一行，下拉框下一行、占满宽度；
      - 隐私黑名单：标题一行，textarea 下一行、占满宽度；
      - 调试模式：标题在上，checkbox 在下、左对齐；
      - 输入法切换：标题在上，select 在下；
      - 字段之间 12px，面板更清爽。
1.3 说明
      .vhcu-field 目前仅用于设置面板（4 处），不影响宏列表/日志行。

        - 合并后 persist，无需手删 macros.json。
2.4 UI
      ⚙ → 系统基础宏组会显示 18 个宏；
      新宏全部出现在宏列表，可启用/禁用、可被 vhcu_get_recommended_macros
      作为通用宏推荐。

6. 已知边界
====================================================================
R1. macro_switch_window 仅发送一次 Alt+Tab；多窗口循环需多次调用。
R2. 新宏依赖目标应用接受标准快捷键；游戏/独占全屏可能无效。
R3. builtin 宏只读，不可编辑/删除，但可启用/禁用。
R4. 设置布局为 CSS 改动，已做源码级断言；实际视觉效果需重启人工确认。
R5. 旧 macros.json 会在加载时自动补入新种子宏，不会覆盖用户自定义宏。
