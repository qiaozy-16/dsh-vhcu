0. 结论（先看这 5 条）
====================================================================
C1. 加载前先检查本地模型：
      <models root>/faster-whisper-base/model.bin
      或 <models root>/model.bin（VHCU_MODEL_PATH 直接指向模型目录）
    存在 → 直接 WhisperModel(str(local_dir), device="cpu", compute_type="int8")；
    **不带 download_root、不触发任何网络请求**。
C2. 本地文件不存在 → 回退原逻辑：base + download_root + 强制 hf-mirror.com。
C3. 明确日志（stderr）：
      使用本地离线模型加载: <local-path>
    同时 hear.status message 也带该文案。
C4. status 增加 offline / loadedPath；UI 提示“使用本地离线模型 …”。
C5. 本机验证：
      local_offline_model_dir() = dsh-vhcu\models\faster-whisper-base
      model.bin exists = True
    测试：Node 45/45、Python 55/55。

1. 实现（vision/vhcu_daemon/hear.py）
====================================================================
1.1 新增 local_offline_model_dir(model_root=None)
      root = Path(model_root) if model_root else default_model_dir()
      for candidate in (root / "faster-whisper-base", root):
          if (candidate / "model.bin").is_file():
              return candidate
      return None
    兼容两种布局：
      models/faster-whisper-base/model.bin   ← 本次用户放置
      models/model.bin                       ← VHCU_MODEL_PATH 指向模型目录
1.2 新增 load_whisper_model(whisper_model_cls, model_root)
      offline = local_offline_model_dir(model_root)
      if offline:
          print(f"使用本地离线模型加载: {offline}", file=sys.stderr, flush=True)
          model = whisper_model_cls(
              str(offline), device="cpu", compute_type="int8"
          )                                  # 无 download_root
          return model, str(offline), True
      force_hf_mirror()                      # 仅下载分支
      model = whisper_model_cls(
          MODEL_NAME, device="cpu", compute_type="int8",
          download_root=str(root)
      )
      return model, str(root), False
1.3 HearService._run
      - 先 emit loading：“检查本地离线模型（models/faster-whisper-base）…”
      - 调 load_whisper_model(...)
      - 再 emit loading message：
          offline=True  → “使用本地离线模型加载: <path>”
          offline=False → “本地模型不存在，从 HF 镜像 … 下载到 …”
      - 记录 self._offline / self._loaded_path
      - 继续 listening / capture。
1.4 status 新增
      "loadedPath": 实际加载路径
      "offline": bool
      （modelPath 仍是 models 根目录）
1.5 Node/UI
      hear.status 映射 offline/loadedPath；
      [H] Hear 提示：
        offline → “使用本地离线模型 <loadedPath>”
        否则     → 镜像下载/模型目录提示。

4. 重启验证
====================================================================
4.1 重启
  完全退出 DSH（确认 Electron/python.exe 无残留）→ 重开 → 新会话。
  日志：
    dsh-vhcu: mounted (routes /vhcu/state|events|control|frame|settings|macros)
    dsh-vhcu: registered 16 tools
4.2 开启 Hear
  VHCU → [H] Hear → 「开启听觉」。
  预期：
    - 守护进程 stderr/DSH 日志出现：
        使用本地离线模型加载: <local-path>
    - 状态点：黄 loading（应很快）→ 绿 listening；
    - 不应再出现 Hugging Face 下载等待/网络超时。
4.3 验证没有联网下载
  - 观察 models\models--Systran--faster-whisper-base 是否不再增长；
  - 断网后重启并开启 Hear，也应能变绿（模型完整时）。
4.4 转写
  播放系统外放音频 → [H] 出现文本 / vhcu_get_hear_events 有事件。
4.5 若仍失败
  - 检查路径是否为 models\faster-whisper-base\model.bin（区分大小写不敏感）；
  - 确认四个文件齐全（model.bin/config.json/tokenizer.json/vocabulary.txt）；
  - 查看 daemon stderr 的 “使用本地离线模型加载” 是否出现；
  - 若报模型损坏，重新从镜像下载完整目录；
  - 若 VHCU_MODEL_PATH 指向了别的目录，请把模型放到该目录下或删除该环境变量。
