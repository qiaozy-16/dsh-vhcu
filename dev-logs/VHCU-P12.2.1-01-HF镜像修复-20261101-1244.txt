====================================================================
1. 问题原因
====================================================================
  faster-whisper 首次加载会通过 huggingface_hub 从
  https://huggingface.co 下载 base 模型。国内直连经常长时间超时，
  HuggingFace 默认超时/重试策略会把界面卡在 loading。
  仅设置环境变量还不够：huggingface_hub 在 import 时会把 HF_ENDPOINT
  读入 constants.ENDPOINT；若在 import 之后才设置，部分下载路径仍用旧值。

====================================================================
2. 修改（vision/vhcu_daemon/hear.py）
====================================================================
2.1 模块级强制（最早时机）
    HF_MIRROR = "https://hf-mirror.com"
    os.environ["HF_ENDPOINT"] = HF_MIRROR
    # 位于 faster_whisper/huggingface_hub 的 import 之前

2.2 force_hf_mirror()
    def force_hf_mirror() -> str:
        os.environ["HF_ENDPOINT"] = HF_MIRROR
        try:
            import huggingface_hub.constants as constants
            constants.ENDPOINT = HF_MIRROR
            if hasattr(constants, "HF_ENDPOINT"):
                constants.HF_ENDPOINT = HF_MIRROR
        except Exception:
            pass
        return HF_MIRROR

2.3 调用点
    - _import_dependencies() 开头：force_hf_mirror()
      （确保 import faster_whisper 前环境已就绪）
    - _run() 中、WhisperModel(...) 之前：endpoint = force_hf_mirror()
      （覆盖已 import 的情况），loading 消息：
        "加载 faster-whisper base（HF_ENDPOINT=https://hf-mirror.com,
         download_root=...）"
2.4 status
    HearService.status() 增加 hfEndpoint: "https://hf-mirror.com"。
2.5 模型路径保持不变
    VHCU_MODEL_PATH 优先；否则 <plugin>/models（D 盘插件目录）。
    download_root 不变，镜像只改变下载源，不改变落盘位置。

5. 重启验证
====================================================================
5.1 安装依赖（若未装）
  py -3 -m pip install soundcard webrtcvad-wheels faster-whisper
5.2 重启
  完全退出 DSH（确认 Electron/python.exe 无残留）→ 重开 → 新会话。
  日志：
    dsh-vhcu: mounted (routes /vhcu/state|events|control|frame|settings|macros)
    dsh-vhcu: registered 16 tools
5.3 开启 Hear
  VHCU → [H] Hear → 「开启听觉」。
  预期 loading 提示包含 hf-mirror.com；下载应明显快于直连 HF。
5.4 检查落盘
  <local-path>
  下应出现 faster-whisper 的 base 模型目录/文件；
  <local-path> 不应新增模型。
5.5 检查状态
  vhcu_start_hear 返回 / hear.status 的 hfEndpoint 应为 https://hf-mirror.com；
  loading 消息包含 HF_ENDPOINT=https://hf-mirror.com。
5.6 若仍慢
  - 镜像本身也可能被网络限制；可尝试在浏览器/命令行访问 https://hf-mirror.com 测试；
  - 或预先手动把 base 模型放到 VHCU_MODEL_PATH 指定目录；
  - 或在 shell 里覆盖 HF_ENDPOINT 后重启（代码会强制改回 hf-mirror.com，
    如需自定义镜像请改 hear.py 的 HF_MIRROR 常量）。
5.7 清理半成品
  若之前卡在下载，models 下可能有 .incomplete 文件；
  huggingface_hub 支持断点续传，一般无需手动删除；异常时可清空 models 后重试。
