2. 本轮交付物
====================================================================
2.1 删除宏
    位置：⚙ 设置 → 宏组 → 点开单个宏 → 详情底部。
    按钮：
      🗑 删除此宏（红色 vhcu-danger）
    安全：
      - builtin === true：不渲染删除按钮；
      - 自定义宏：第一次点击进入确认态
        「⚠ 再点一次确认删除」，再点才调用；
      - 可点「取消删除」退出确认；
      - 成功后调用已有 POST /vhcu/macros {action:"delete",name}，
        关闭详情并刷新宏列表；
      - 失败显示 Node 返回错误，恢复按钮态。
    说明：P19.2 之前已有删除按钮，但文案为普通「删除宏」且不显眼；
          本次改为红色全宽按钮 + 二次确认，避免误删。

2.2 导入宏
    位置：宏组页面「+ 新建宏」旁边的 [📥 导入宏]。
    交互：
      - 展开文本域，粘贴单个宏 JSON 或数组；
      - 支持：
          {name,description,target_app,steps}
          [{...},{...}]
          {macros:[...]}
          {macro:{...}}
      - 前端校验：1..20 个、每个必须有 name、steps 非空且 ≤50 步；
      - 导入分类：当前自定义宏组；若在「系统基础宏」组则回退
        「我的自定义宏」；
      - builtin 字段不会保留（服务端 add 强制 builtin=false）；
      - 逐个调用 POST /vhcu/macros {action:"save"}；
      - 任一失败显示“第 N 个导入失败：...”，已成功的保留；
      - 成功后关闭导入框并刷新列表。

2.3 导出宏
    位置：宏详情 [📤 导出]（内置宏也可导出）。
    交互：
      - 取当前已保存宏（不是编辑中的文本）；
      - 生成：
          {name,description,category,target_app,steps}
      - 以只读 textarea 展示；
      - 点击文本自动全选；
      - [📋 复制] 使用 navigator.clipboard；
        不可用时提示“请选中 JSON 手动复制”；
      - [收起导出] 关闭。
    不包含 builtin/运行时字段，便于他人导入。

2.4 宏失败自动降级
    新增 host/lib/macros.js：
      export const MACRO_RECOVERY_HINT =
        '⚠️ 宏执行失败：可能由于窗口位置改变或加载延迟导致。' +
        '建议：立刻切换为视觉慢车道（调用 vhcu_get_full_frame 观察屏幕），' +
        '重新规划动作并执行。';
      export function withMacroRecoveryHint(hint) { ... }
    接入：
      - executeStoredMacro 捕获异常：
          hint = withMacroRecoveryHint(error.hint)
      - executeStoredMacro 截图校验失败/坐标越界 warnings：
          返回 hint = MACRO_RECOVERY_HINT
      - executeMacroQueue 任一步失败/verify 失败：
          hint = withMacroRecoveryHint(原 hint / 队列中止提示)
    效果：
      模型收到 vhcu_run_macro 或 vhcu_run_macro({macros_queue}) 失败时，
      hint 中一定包含“切换为视觉慢车道 + vhcu_get_full_frame”的强提示。

4. 风险与未验证项
====================================================================
R1. 删除为二次确认，第一次点击不会立即删除；这是防误删设计。
R2. 导入失败可能部分成功（逐个保存），提示第几个失败；
    已导入的前 N 个不会回滚。
R3. 导入分类固定为当前组；跨组导入需要先切组。
R4. 导出复制依赖 navigator.clipboard；不可用时只能手动选中。
R5. “坐标点击未生效”本身无法由 SendInput 返回值检测；
    当前 hint 覆盖：E_MACRO_FAILED、宏步骤异常、截图校验失败、
    坐标越界 warnings。真正的“点击成功但界面无变化”仍需
    模型主动调用 vhcu_get_full_frame 观察。
R6. 内置宏不可删除；只可禁用/启用或导出复制。
R7. 本轮未改 Python 宏执行器。
